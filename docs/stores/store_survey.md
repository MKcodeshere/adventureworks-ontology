# Store Survey Notes

Each reseller store fills an annual StoreSurvey (XML demographics).

Fields include AnnualSales, AnnualRevenue, BankName, BusinessType,

YearOpened, Specialty, SquareFeet, Brands, Internet, NumberEmployees.

Specialty values seen in data: Mountain, Road, Touring, Family.

BusinessType values: OS = Outlet Store, VS = Value Store, AW = Adventure Works specialty.
